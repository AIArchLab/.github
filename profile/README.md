# AIArchLab

**From strategy to production: it runs in production, it stays under control, and it can be rolled back.**

AIArchLab is an independent consulting studio for enterprise AI adoption. We assess readiness,
design governance as executable control, and prove value in a small pilot before anything scales.

## What we believe

1. Governance = policy + executable checks.
2. Reputation is no substitute for verification.
3. Governance must manage the actual operating state, not the declared state.

## How we work

- **Small pilot first.** No program scales before a pilot has run in production and survived it.
- **Evidence over promises.** Every claim ships with something you can run, read, or reproduce.
- **Reversible by design.** Every change can be rolled back; every decision leaves an audit trail.
- **De-identified by default.** Public materials never name clients, members, or budgets.

## What we do

- **AI Readiness Assessment** — a two-week remote assessment:
  process inventory, data boundaries, pilot design, and an AI usage policy.
  Starts with a 30-minute scoping call.

## What we publish here

Works, not articles. Tools you can run and evidence you can inspect.
